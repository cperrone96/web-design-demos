# Web Design Demos

Hand-built, responsive marketing websites for three fictional local-service
businesses. Each is a complete multi-page site written in **plain HTML & CSS**
(no frameworks, no page builders) — clean, fast-loading, mobile-first, and
conversion-focused.

## Demos

| Site | Industry | Pages | Live |
|---|---|---|---|
| **Green Horizons** | Landscaping / lawn care | 8 | [green-horizons](https://datadesigndynamics.org/demos/green-horizons/index.html) |
| **Climate Pro** | HVAC (heating & cooling) | 16 | [climate-pro](https://datadesigndynamics.org/demos/climate-pro/index.html) |
| **Shield Pest** | Pest control | 4 | [shield-pest](https://datadesigndynamics.org/demos/shield-pest/index.html) |

## What they show

- Semantic, accessible HTML structure
- Responsive, mobile-first CSS (custom design system per brand)
- Multi-page information architecture (services, service-area, testimonials,
  FAQ, contact, booking/financing, etc.)
- Conversion-oriented layout: clear calls-to-action, trust signals, local SEO
  structure

## Run locally

No build step. Clone and open any `index.html` in a browser, or serve the
folder:

```bash
cd climate-pro && python3 -m http.server 8000
# then open http://localhost:8000
```
